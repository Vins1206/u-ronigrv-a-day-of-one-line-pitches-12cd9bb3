One sentence, written for a friend who has never coded, that makes the case for letting an AI agent build their first app idea on make.fun. It leads with the idea they already carry around, promises only a working first version, and removes every reason to hesitate: they just watch, there is no coding, and there is nothing to install.

The sentence (166 characters):

> Tell me the app idea you've been carrying around, and let an AI agent on make.fun build you a working first version while you watch, no coding and nothing to install.

## Run it

```sh
python3 main.py
```

This writes the sentence to `/output/entry.txt` (UTF-8, deterministic, standard library only, no network).
